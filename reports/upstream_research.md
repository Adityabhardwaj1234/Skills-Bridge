## 2. Deep Technical Audit of Each Upstream Repository

### 2.1 NVIDIA SkillSpector (`95a52d89fa16f608f0b18ccee76b0918ea4b7eef`)
1. **Static & Behavioral Analyzer Architecture**:
   - Implemented as a LangGraph workflow (`src/skillspector/graph.py`) with 30+ analyzer modules under `src/skillspector/nodes/analyzers/`:
     - **Static Pattern Families**: `static_patterns_prompt_injection.py`, `static_patterns_data_exfiltration.py`, `static_patterns_privilege_escalation.py` (e.g. `PE3`), `static_patterns_supply_chain.py`, `static_patterns_ssrf.py`, `static_patterns_deserialization.py`, `static_patterns_agent_snooping.py`, `static_patterns_anti_refusal.py`, `static_patterns_excessive_agency.py`, `static_patterns_memory_poisoning.py`, `static_patterns_rogue_agent.py`, `static_patterns_system_prompt_leakage.py`, `static_patterns_tool_misuse.py`, `static_yara.py`.
     - **Python AST & Lexical-Scope Taint Tracking (`TT1`–`TT6`)**: `behavioral_ast.py` detects `exec`, `eval`, `compile`, `__import__`, and reflective `getattr` sinks; `behavioral_taint_tracking.py` tracks data flows from sensitive sources (environment variables, credential files, network inputs) to network/exec/file sinks across lexical scopes and intra-file function calls.
     - **Unicode, Whitespace Padding & Obfuscation**: `unicode_confusables.py`, `whitespace_padding.py`, and `security_reconstruction.py` detect zero-width smuggling, confusable homoglyphs, and newline-split obfuscated instructions (`AE6` / `obfuscated_instruction_text`).
     - **MCP Least-Privilege (`B.3.1`, `LP1`–`LP4`) & Tool Poisoning (`B.3.2`, `TP1`–`TP4`)**: `mcp_least_privilege.py` audits `allowed-tools` grants against instructions (`wildcard` grants, unused high-risk tools, undeclared tool usage); `mcp_tool_poisoning.py` and `mcp_rug_pull.py` inspect MCP tool descriptions for hidden instructions, whitespace padding, and cross-server shadowing.
2. **Inspection Ledger & Scan Completeness (`inspection_ledger.py` & `docs/scan-completeness.md`)**:
   - Every file and analyzer records a `LedgerOutcome` (`completed`, `partial`, `skipped`, `failed`, `out_of_scope`) and `LedgerReason` (`size_limit`, `binary_content`, `syntax_error`, `analyzer_runtime_error`, `unsupported_primary_content`).
   - Output JSON includes `analysis_completeness` (`is_complete: bool`, `status: "complete" | "incomplete"`, `coverage_percent`, `analyzer_statuses[]`, `ledger_exceptions[]`).
   - **Critical Invariant**: Recognized unsupported required content, unresolved covered reconstruction, or failed analyzers mark `is_complete: false` and exit with code `2` so incomplete scans are never mistaken for `SAFE`.
3. **MCP Server Integration (`src/skillspector/mcp_server.py`)**:
   - Exposes `run_scan()` (independent of the `mcp` SDK) and `build_server()` (FastMCP wrapper exposing `scan_skill`).

### 2.2 NVIDIA SkillEvaluator (`6068b3a6d8895430c0ff35c89635e58f2d99f1c2`)
1. **Three-Tier Architecture**:
   - **Tier 1 (`src/skillevaluator/tier1/commands.py`)**: Runs deterministic validators (`SchemaValidator`, `FrontmatterParser`, `MarkdownValidator`, `HygieneValidator`, `LicenseValidator`, `VersionValidator`, `SecretsValidator`, `UnicodeSmuggleValidator`, `DependencySecurityValidator`, `ScriptLintValidator`, `CodeRiskValidator`, `QualityScoreValidator`, `SecurityValidator`).
   - **Non-Redundant SkillSpector Integration**: `SecurityValidator` (`src/skillevaluator/validators/security.py`) shells out to `skillspector scan <path> --format json --no-llm` and checks `_SKILLSPECTOR_COMPLETENESS_SCHEMA_VERSION >= (2, 10, 0)`. In SkillBridge v2, because Tier 1 already runs `SkillSpectorAdapter` directly, `SkillEvaluatorAdapter` is configured to pass/reuse the Tier 1 SkillSpector evidence or run only SkillEvaluator's structural quality, hygiene, license, script-lint, and PII validators (`--skip-skillspector` / selective validator mode) so SkillSpector is **never executed twice on the same bundle**.
   - **Tier 2 (`src/skillevaluator/tier2/commands.py`)**: Runs `IntraSkillValidator` (detecting redundant/contradictory sections inside a skill) and `SimilarityValidator` (detecting inter-skill overlap against a catalog with configurable `--threshold 0.75`).
   - **Tier 3 (`src/skillevaluator/tier3/workflow.py`)**: Generates synthetic evaluation datasets (`create-eval-dataset`) and executes paired **with-skill vs. without-skill** trials in isolated environments (`--env-mode docker|gke|local`), measuring **Skill Lift** (`score_delta`, `pass@k`, token delta, execution latency, and cost).

### 2.3 SKIL — Skill Inspector and Linter (`9016d9a21c5e1a2b5fb9c11b97100d444f7d7071`)
1. **Six-Stage Assurance Pipeline**:
   - Separates `contract`, `analysis`, `assurance closure`, `verification`, `policy`, and `attestation`.
   - **Declared-vs-Observed Capability Verification (`internal/verification/`)**: Compares capabilities declared in `SKILL.md` / `skill.contract.yaml` (`filesystem`, `network`, `exec`, `env`, `mcp`) against capabilities statically observed in scripts and instructions (including Python variable-alias resolution `runner = subprocess.run; runner(cmd, shell=True)`).
   - **Deterministic Assurance Closure (`internal/assurance/closure.go`)**: Builds a canonical graph of `ClosureNode` (`root`, `artifact`, `dependency`, `external_reference`, `nested_artifact`, `mcp_surface`, `runtime_artifact`, `agent_execution_surface`, `persistent_state`) and `ClosureEdge` (`contains`, `depends-on`, `configures`, `loads`, `references`). Sorts and hashes nodes/edges with SHA-256 independent of traversal order.
   - **Three-Valued Assurance State (`pkg/skil/models.go`)**:
     - `SAFE`: Every required node is resolved, fully analyzed, verified, and has no blocking findings.
     - `UNSAFE`: At least one required node has a blocking verdict or `HIGH`/`CRITICAL` finding (`UNSAFE` dominates `UNKNOWN`).
     - `UNKNOWN`: Any required node is missing, unresolved, skipped, failed, budget-exceeded, or unverified.
   - **Host Runtime Gateway Boundary**: SKIL provides `internal/gate` and `internal/runtimeproxy`, explicitly documenting that scan verdicts do not enforce runtime operations unless the host runtime mediates calls through a fail-closed capability gateway. SkillBridge models this honestly: SkillBridge enforces capability checks inside its own `ScriptWorker` and `MCPBroker`, while documenting that standalone native clients without a runtime gateway only receive pre-install/pre-load assurance.

### 2.4 Qualixar SkillFortify (`dbb5942deae46afdb5b85440d5f5d851c197c30e`)
1. **Capabilities & Architecture Audited**:
   - Provides multi-framework discovery (`src/skillfortify/discovery/`), static capability inference (`READ`/`WRITE`/`EXECUTE` across filesystem, network, env, subprocess), POLA (Principle of Least Authority) violation detection (`skillfortify verify`), 4-signal trust algebra (`provenance`, `behavioral`, `community`, `historical` in `skillfortify trust`), deterministic `skill-lock.json` generation (`SOURCE_DATE_EPOCH` support), and CycloneDX 1.6 ASBOM generation (`skillfortify sbom`).
2. **Documentation Claims vs. Code Reality**:
   - While commands like `skillfortify verify` describe "formal verification" and `level: "FORMALLY_VERIFIED"`, inspection of `src/skillfortify/core/` shows that capability inference is heuristic regex/AST pattern matching paired with optional SAT-based dependency resolution (`python-sat`), and `SkillFortifyBench` (`benchmarks/README.md`) candidly notes that its 540-specimen corpus is a **deterministic synthetic seed-generated corpus** (`SKILLFORTIFYBENCH:INERT`) that measures recognition of 13 known attack templates (`A1`–`A13`) rather than real-world field accuracy.
3. **Strict License Gate Decision (Elastic License 2.0)**:
   - `skillfortify` is licensed under **Elastic License 2.0**, and its source files include `src/skillfortify/_watermark.py` and `qualixar_watermark.py`.
   - **Mandatory Compliance Action**: SkillBridge **does not copy, vendor, port, or redistribute any code, watermark, or benchmark specimen from `skillfortify`**. Instead, `OptionalSkillFortifyAdapter` is implemented purely from the public CLI specification (`skillfortify scan <path> --format json`, `skillfortify verify <path> --format json`, `skillfortify trust <path> --format json`), remains **disabled by default** (`enable_skillfortify=False`), and executes only if a user independently installs `skillfortify` on their system and explicitly opts in after reviewing the Elastic License 2.0.
